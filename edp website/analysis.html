Phase 1 — Data Preprocessing

Cleaning & preparing the dataset

The raw dataset contained mixed data types, missing values, and encoding issues (special characters in non-English artist names). We handled all of these before any analysis.

  • Shape: 4,600 rows × 29 columns after loading
  • Missing values: Numeric stream columns had ~12% nulls — filled with 0 for aggregation, dropped for ratio calculations
  • Encoding: Used latin-1 encoding to handle special characters in track/artist names
  • Type conversion: Stream columns stored as strings with commas — converted to numeric using pd.to_numeric
  • NumPy stats: Used np.percentile and np.median for outlier detection and normalization
Python
# Load dataset import pandas as pd import numpy as np df = pd.read_csv('spotify_2024.csv', encoding='latin-1') # Clean stream columns cols = ['Spotify Streams', 'YouTube Views', 'TikTok Views'] for col in cols: df[col] = pd.to_numeric( df[col].str.replace(',',''), errors='coerce' ) # Check nulls print(df.isnull().sum()) # NumPy: outlier cap at 95th %ile cap = np.percentile( df['Spotify Streams'].dropna(), 95 )

Project Phases

How we built this project

A step-by-step breakdown of our methodology from data loading to final visualizations.

Phase 1
Dataset Selection & Loading
Downloaded Most Streamed Spotify Songs 2024 from Kaggle. Loaded into Pandas with latin-1 encoding. Verified shape (4,600 × 29) and previewed all column names and data types.
Phase 2
Data Preprocessing
Cleaned numeric columns stored as comma-separated strings. Handled ~12% missing values in stream columns. Used NumPy for percentile-based outlier detection and MinMaxScaler for normalization.
Phase 3
Exploratory Data Analysis
Computed descriptive statistics (mean, median, std, percentiles). Used groupby aggregations for artist-level, album-level and month-level analysis. Identified key trends in platform behavior and release timing.
Phase 4
Feature Engineering
Extracted featured artists from track names using regex. Detected song language using the langdetect library. Created composite loyalty index from weighted platform engagement ratios. Derived release month, day and year from date column.
Phase 5
Visualization
Built 9 charts using Matplotlib and Seaborn — including scatter plots, animated bar races, pie charts, multi-line timelines and horizontal bar charts. All charts saved as PNG and embedded in this website.
