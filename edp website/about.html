Tech Stack

Tools & libraries used

🐍
Python 3.12
Core programming language for all data processing, analysis and visualization.
🐼
Pandas
Data loading, cleaning, groupby aggregations, and feature engineering.
🔢
NumPy
Statistical computations — percentiles, normalization, outlier detection.
📊
Matplotlib
Primary charting library — bar charts, scatter plots, pie charts, animations.
🎨
Seaborn
Advanced visualizations — heatmaps and styled statistical plots.
🔤
langdetect
Language detection from track names — used for language distribution analysis.
⚗️
scikit-learn
MinMaxScaler for normalizing platform metrics in the loyalty index calculation.
📓
Google Colab
Cloud-based Jupyter notebook environment — no local setup required.
🌐
HTML / CSS / JS
This website — built as a bonus deliverable to present findings interactively.
